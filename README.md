## About

I build web software end to end — Laravel applications with real business logic, custom **WordPress / WooCommerce** plugins, and fast, privacy-first browser tools. Based in **Satkhira, Bangladesh**, currently shipping at [@Oblique-Code](https://github.com/Oblique-Code). I care about maintainable backends, clear interfaces, and the details that hold up in everyday use.
